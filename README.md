# erpriliano.github.io

Personal portfolio website for Erpriliano Abbas, rebuilt from Gatsby to Astro.

## Stack

- Astro
- TypeScript
- Static content collections
- GitHub Pages via GitHub Actions

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deployment

The site deploys through `.github/workflows/deploy.yml` when changes are pushed to `development`. GitHub Pages should be configured to use **GitHub Actions** as the publishing source.
